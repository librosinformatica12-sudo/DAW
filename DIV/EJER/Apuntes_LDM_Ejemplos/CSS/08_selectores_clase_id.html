En CSS 2.1 existen los siguientes tipos de selectores:

  • Selector universal: *
  • Selector de tipo: p
  • Selector de descendientes: div p
  • Selector de hijos: div > p
  • Selector adyacente: h1 + h2
  • Selector de atributos: [type="text"]
  • Selector de clase: .rojo
  • Selector de ID: #introduccion
  • Selector de pseudo-clase: a:hover
  • Selector de pseudo-elemento: p::first-line
