Cabecera de un documento

Completa la cabecera de una página con la codificación, la dirección base, los metadatos, el favicon y el título. El contenido visible será un sencillo “Hola Mundo”.

Fíjate: el título no aparece dentro de la página; se muestra en la pestaña del navegador. En el PDF la etiqueta base usa una URL absoluta, pero aquí utilizamos ./ para que el ejercicio funcione en local.

Hola Mundo!!!

Esta página ya tiene una cabecera completa: codificación UTF-8, descripción, palabras clave, autor, favicon y título.

La manzana de la pestaña es el favicon en formato SVG.

Qué se practica

  • <meta charset>
  • <base>
  • <meta name="author">
  • <meta name="description">
  • <meta name="keywords">
  • <link rel="icon">
  • <title>
Ver el código clave 
<base href="./">
        <meta name="author" content="Alumno de LDM">
        <meta name="description" content="Ejercicio de la cabecera">
        <meta name="keywords" content="HTML, CSS, LDM">
        <link rel="icon" href="manzana.svg" type="image/svg+xml">
        <title>01 · Cabecera de un documento</title>
