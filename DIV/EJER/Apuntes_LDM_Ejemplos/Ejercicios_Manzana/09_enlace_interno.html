Enlaces dentro de la misma página

Crea un índice que salte a distintas secciones de esta misma página. Cada sección debe tener un id y un enlace para volver arriba.

Cómo funciona: el destino se marca con id="nombre" y el enlace usa href="#nombre". El símbolo # significa “dentro de este documento”.

Índice

  1. HTML
  2. CSS
  3. XML
  4. JavaScript

HTML

HTML significa HyperText Markup Language. Es el lenguaje que estructura el contenido de una página: títulos, párrafos, listas, enlaces, imágenes, formularios y tablas.

Un documento HTML se compone de una cabecera, donde van los metadatos, y un cuerpo, donde va lo que ve el usuario.

CSS

CSS significa Cascading Style Sheets. Se encarga de la presentación: colores, tipografías, márgenes, tamaños, distribución y animaciones.

Separar HTML y CSS permite cambiar el aspecto de todo un sitio sin reescribir su estructura.

Volver arriba

XML

XML significa eXtensible Markup Language. No tiene etiquetas predefinidas: cada vocabulario define las suyas para describir datos.

Se usa para intercambiar información entre sistemas, guardar configuración y representar documentos estructurados.

Volver arriba

JavaScript

JavaScript es el lenguaje de programación del navegador. Añade comportamiento: responde a clics, valida formularios, modifica el DOM y se comunica con servidores.

No es un lenguaje de marcas, pero convive con HTML y CSS en la mayoría de páginas web.

Volver arriba

Qué se practica

  • id único en cada destino
  • href="#destino"
  • Índice de navegación
  • Enlace de vuelta a #inicio
Ver el código clave 
<h1 id="inicio">Enlaces dentro de la misma página</h1>
<a href="#xml">Ir a XML</a>

<h2 id="xml">XML</h2>
<p>...</p>

<a href="#inicio">Volver arriba</a>
