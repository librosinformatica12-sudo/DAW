Enlaces externos en la misma pestaña

Crea enlaces a páginas de otros servidores. Al no indicar target, el navegador sustituye la página actual por el destino.

Consejo: usa enlaces externos para ampliar información, no para sustituir el contenido del ejercicio. Escribe siempre un texto de enlace descriptivo.

Documentación y referencias

  • Documentación de HTML 4.01 en el W3C
  • Referencia de HTML en MDN
  • HTML en Wikipedia

Si haces clic en uno de estos enlaces, esta página se cerrará y se abrirá el destino en la misma pestaña.

Qué se practica

  • href con URL absoluta
  • Enlace sin target
  • Texto de enlace descriptivo
  • Diferencia entre enlace interno y externo
