Enlaces externos en una pestaña nueva

Abre varias referencias externas en una pestaña nueva con target="_blank" y añade rel="noopener noreferrer" por seguridad.

Importante: cuando uses target="_blank", añade rel="noopener". Evita que la página abierta pueda manipular la pestaña original. noreferrer oculta además la procedencia.

Referencias para seguir practicando

  • CSS en el W3C (nueva pestaña)
  • Referencia de CSS en MDN (nueva pestaña)
  • Curso de CSS en web.dev (nueva pestaña)
  • CSS en Wikipedia (nueva pestaña)

Los enlaces de esta lista conservan esta página abierta y muestran el destino en otra pestaña.

Qué se practica

  • target="_blank"
  • rel="noopener"
  • rel="noreferrer"
  • Enlaces externos seguros
Ver el código clave 
<a href="https://www.w3.org/Style/CSS/"
   target="_blank"
   rel="noopener noreferrer">
  CSS en el W3C (nueva pestaña)
</a>
