Formulario de datos personales

Crea un formulario con los controles básicos: usuario, contraseña, sexo, condición de socio, temas preferidos, descuento de solo lectura, fichero adjunto, campo oculto y botones.

Accesibilidad: cada control debe tener su label asociado mediante for e id. Los grupos de radio comparten el mismo name para que solo se pueda elegir una opción.
Datos de acceso
Sexo:
Temas preferidos
Envío

Qué se practica

  • <form> con action y method
  • input type="text" y password
  • checkbox y radio
  • readonly y hidden
  • input type="file"
  • textarea
  • fieldset y legend
  • Botones submit, reset y button
Ver el código clave 
<form action="#" method="post" enctype="multipart/form-data">
  <label for="usuario">Usuario:</label>
  <input type="text" id="usuario" name="usuario">

  <label for="pass">Contraseña:</label>
  <input type="password" id="pass" name="pass">

  <label><input type="checkbox" name="socio" checked> Soy socio</label>

  <label><input type="radio" name="genero" value="H"> Hombre</label>
  <label><input type="radio" name="genero" value="M" checked> Mujer</label>

  <input type="text" name="descuento" value="15%" readonly>
  <input type="file" id="fichero" name="fichero">
  <input type="hidden" name="fecha" value="2026-11-16">

  <input type="submit" value="Enviar">
  <input type="reset" value="Borrar">
</form>
