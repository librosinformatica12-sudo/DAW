Formulario de pedido: Fábricas Toledo

Recrea el formulario de pedido con tres bloques: identificación del cliente, datos del producto y envío, y datos bancarios. Usa fieldsets, labels, un select con optgroup y una zona de comentarios.

Agrupación: los fieldset separan partes del formulario y legend da nombre a cada parte. Así el formulario es más fácil de leer y de navegar con teclado.

Qué se practica

  • form con action y method
  • Varios fieldset y legend
  • input type="email"
  • select con optgroup
  • radio, textarea
  • Validación con required y pattern
  • Botones de envío y reset
Ver el código clave 
<form action="#" method="post">
  <fieldset>
    <legend>1. Identificación</legend>
    <label for="nombre">Nombre:</label>
    <input type="text" id="nombre" name="nombre" required>

    <label><input type="radio" name="tipo" value="particular" checked> Particular</label>
  </fieldset>

  <fieldset>
    <legend>2. Pedido</legend>
    <select id="producto" name="producto">
      <optgroup label="Armaduras">
        <option value="AR001">AR001 Oro Reluciente</option>
      </optgroup>
    </select>
    <textarea id="comentarios" name="comentarios"></textarea>
  </fieldset>

  <input type="submit" value="ENVIAR PEDIDO">
  <input type="reset" value="RESET">
</form>
