Tablas con imágenes: efecto Warhol

Coloca una misma imagen en una tabla de 3 × 3 y aplica un filtro CSS distinto a cada copia para conseguir un efecto pop art inspirado en Andy Warhol.

Una sola imagen: todas las celdas usan el mismo archivo warhol.svg. Lo que cambia es la clase CSS de cada imagen, que aplica filter con combinaciones de tono, saturación, sepia, brillo e inversión.
Retrato pop art · 3 × 3

Qué se practica

  • Imágenes dentro de celdas
  • Tabla de 3 filas y 3 columnas
  • table-layout: fixed
  • Filtros CSS con filter
  • Combinaciones de hue-rotate
  • saturate, sepia e invert
Ver el código clave 
<table class="warhol-tabla">
  <tbody>
    <tr>
      <td><img class="f1" src="warhol.svg" alt="Retrato rosa"></td>
      <td><img class="f2" src="warhol.svg" alt="Retrato en gris"></td>
      <td><img class="f3" src="warhol.svg" alt="Retrato verde"></td>
    </tr>
  </tbody>
</table>

<style>
  .warhol-tabla img { width: 100%; display: block; }
  .f1 { filter: sepia(1) saturate(4) hue-rotate(300deg); }
  .f2 { filter: grayscale(1) contrast(1.5); }
  .f3 { filter: hue-rotate(90deg) saturate(2.4); }
</style>
