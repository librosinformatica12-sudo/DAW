Listas ordenadas y no ordenadas

Muestra los mismos lenguajes de marcas en una lista ordenada y en una lista no ordenada para comparar el efecto de ol y ul.

Elige por significado: usa ol cuando el orden importa (pasos, ranking, instrucciones) y ul cuando solo agrupas elementos sin prioridad.

Lenguajes de Marcas en lista ordenada <ol>

  1. HTML
  2. XHTML
  3. XML

Lenguajes de Marcas en lista no ordenada <ul>

  • HTML
  • XHTML
  • XML

Qué se practica

  • <ol>: lista ordenada
  • <ul>: lista no ordenada
  • <li>: elemento de lista
  • Anidación correcta dentro de li
Ver el código clave 
<h2>Lista ordenada</h2>
<ol>
  <li>HTML</li>
  <li>XHTML</li>
  <li>XML</li>
</ol>

<h2>Lista no ordenada</h2>
<ul>
  <li>HTML</li>
  <li>XHTML</li>
  <li>XML</li>
</ul>
