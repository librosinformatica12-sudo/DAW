Listas anidadas

Agrupa lenguajes de marcas en una lista ordenada principal y añade una lista no ordenada dentro de cada categoría para enumerar sus ejemplos.

Regla de oro: la lista interna debe ir dentro del <li> al que pertenece, no entre dos <li> sueltos.

Lenguajes de Marcas en Listas Anidadas

  1. Páginas Web
    • HTML
    • XHTML
  2. Dispositivos móviles
    • XHTML MP
  3. Documentos
    • RTF
    • Tex
    • MathML
  4. Gráficos
    • SVG
    • STEP
  5. Específicos
    • SMIL
    • WSDL

Qué se practica

  • Anidar ul dentro de li
  • Combinar ol y ul
  • Mantener una jerarquía legible
  • Cerrar cada nivel en el orden correcto
Ver el código clave 
<ol>
  <li>Páginas Web
    <ul>
      <li>HTML</li>
      <li>XHTML</li>
    </ul>
  </li>
  <li>Documentos
    <ul>
      <li>RTF</li>
      <li>Tex</li>
      <li>MathML</li>
    </ul>
  </li>
</ol>
