Tablas con datos

Presenta un conjunto de datos en una tabla semántica: título, cabecera de columnas, cuerpo, fila de totales, alineación de números y una fuente bajo la tabla.

No es una tabla de maquetación: esta tabla relaciona cada comunidad con tres cifras. Por eso usamos th scope="col" y th scope="row", que indican qué encabezado corresponde a cada dato.

Cifras redondeadas y usadas como ejemplo didáctico. No sustituyen a los datos oficiales del INE.

Qué se practica

  • caption descriptivo
  • thead, tbody y tfoot
  • th scope="col"
  • th scope="row"
  • colgroup y col
  • Alineación de cifras con CSS
  • Fuente de los datos
Ver el código clave 
<table class="tabla">
  <caption>Población de algunas comunidades (2024)</caption>
  <thead>
    <tr>
      <th scope="col">Comunidad autónoma</th>
      <th scope="col">Hombres</th>
      <th scope="col">Mujeres</th>
      <th scope="col">Total</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Andalucía</th>
      <td>4.236.000</td>
      <td>4.395.000</td>
      <td>8.631.000</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <th scope="row">Total</th>
      <td>18.939.000</td>
      <td>19.702.000</td>
      <td>38.641.000</td>
    </tr>
  </tfoot>
</table>
