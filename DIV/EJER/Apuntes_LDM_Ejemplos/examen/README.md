# Examen de práctica · DIV

Simulacro de examen de **Diseño de Interfaces Web** (2.º DAW).

## Cómo usarlo

1. Abre `index.html`.
2. Lee el `enunciado.html` (tareas, puntuación y criterios).
3. Haz el `test.html` para repasar teoría.
4. Intenta cada práctica con su **plantilla** antes de mirar la **solución**.

## Temas que repasa

- Flexbox: barra de navegación, alineación y tarjetas.
- CSS Grid: `grid-template-areas`, columnas y zonas.
- Responsive: variables CSS, `rem`, `media queries` y `clamp()`.
- Accesibilidad: `label`/`for`, `alt`, `aria-label`, `:focus` y contraste.
- Animaciones: `transition`, `transform`, `@keyframes` y
  `prefers-reduced-motion`.

## Autoevaluación

- ¿Funciona en el navegador sin romperse al reducir la ventana?
- ¿El CSS está ordenado y sin reglas duplicadas?
- ¿Usas etiquetas semánticas y textos alternativos?
- ¿La página se entiende solo con teclado?
- ¿Has respetado la reducción de movimiento?

Si todo es «sí», tienes el nivel esperado para el examen.
