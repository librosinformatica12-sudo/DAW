Modelo de Datos: Objeto Usuario (Sakila DB)

Definición PHP / JavaScript para la integración con la base de datos relacional Sakila

En la base de datos Sakila, los usuarios interactúan a través de las tablas customer y staff. A continuación se detalla la estructura mapeada del objeto Usuario para esta aplicación web: 

class SakilaUser {
    public int $customer_id;      // Clave primaria (Auto-increment)
    public int $store_id;         // ID de la tienda del videoclub (1 o 2)
    public string $first_name;    // Nombre (máx 45 chars)
    public string $last_name;     // Apellido (máx 45 chars)
    public string $email;         // Correo electrónico único
    public int $address_id;       // ID de dirección postal en tabla address
    public bool $active;          // Estado activo (1 = activo, 0 = inactivo)
    public string $username;      // Nombre de usuario para login web
    public string $password_hash; // Hash seguro de contraseña (Bcrypt/Argon2)
    public string $create_date;   // Fecha de registro automática (TIMESTAMP)
    public string $last_update;   // Última actualización de datos
}
Nota DAW: Este modelo prepara el terreno para enlazar con las tablas relacionales de alquileres (rental) y pagos (payment) de Sakila una vez que el usuario inicie sesión correctamente.
