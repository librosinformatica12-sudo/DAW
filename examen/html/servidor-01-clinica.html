Hueco 6 — Procedimiento AltaCita

CREATE PROCEDURE AltaCita(
    IN _paciente VARCHAR(50),
    IN _especialidad VARCHAR(30),
    IN _fecha DATETIME,
    IN _doctor INT,
    OUT _res INT
)
BEGIN
    IF (/* nombre vacío */) THEN
        SET _res = -1;
    ELSEIF (/* fecha anterior a hoy */) THEN
        SET _res = -4;
    ELSEIF (/* el doctor no existe */) THEN
        SET _res = -5;
    ELSE
        INSERT INTO citas(paciente, especialidad, fecha, fk_doctor)
        VALUES(_paciente, _especialidad, _fecha, _doctor);
        SET _res = 0;
    END IF;
END
Ver solución 
IF (_paciente = '' OR _paciente IS NULL) THEN
    SET _res = -1;
ELSEIF (_fecha <= NOW()) THEN
    SET _res = -4;
ELSEIF NOT EXISTS (SELECT 1 FROM doctores WHERE n_licencia = _doctor) THEN
    SET _res = -5;
ELSE
    INSERT INTO citas(paciente, especialidad, fecha, fk_doctor)
    VALUES(_paciente, _especialidad, _fecha, _doctor);
    SET _res = 0;
END IF;

Posibles preguntas del profe

  1. ¿Por qué session_start() va antes del HTML? Porque las cabeceras deben enviarse antes de cualquier salida.
  2. ¿Qué hace htmlspecialchars? Convierte <, >, &, comillas... en entidades y evita XSS.
  3. ¿Qué letra de bind_param usarías para el precio? d (double/decimal).
  4. ¿Qué pasa si el OUT devuelve null? (int)null es 0, por eso conviene comprobar que el procedure asigna siempre _res.
  5. ¿Por qué no se puede pasar '' a un DATETIME? Porque MySQL lo rechaza en modo estricto. Se valida antes en PHP.
  6. ¿Diferencia entre require y require_once? require_once no vuelve a cargar el archivo si ya se cargó; evita errores de funciones duplicadas.
