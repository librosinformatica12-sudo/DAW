Ejercicio Servidor 03 — Biblioteca

Enunciado general: gestionar libros, socios y préstamos.

  • Alta de libros y socios.
  • Listar libros mostrando cuántos ejemplares quedan disponibles.
  • Prestar un libro si hay existencias.
  • Devolver un préstamo.

Este ejemplo añade algo que no tienen los otros: JOIN, subconsultas y UPDATE de estado.

Posibles preguntas del profe

  1. ¿Qué diferencia hay entre INNER JOIN y LEFT JOIN? INNER JOIN solo devuelve filas con coincidencia; LEFT JOIN devuelve también las de la izquierda sin coincidencia.
  2. ¿Por qué devuelto es TINYINT(1)? Porque MySQL no tiene booleano puro; TINYINT(1) se usa como 0/1.
  3. ¿Por qué calcular disponibles en SQL y no en PHP? Porque la base de datos ya tiene los datos y evita traer todos los préstamos.
  4. ¿Qué pasa si se presta el último ejemplar dos veces a la vez? Podría haber condición de carrera; se resolvería con transacción y bloqueo.
  5. ¿Qué hace NOW()? Devuelve la fecha y hora actual del servidor MySQL.
  6. ¿Cómo comprobarías que un socio existe antes de prestar? Con EXISTS (SELECT 1 FROM socios WHERE id_socio = _socio), como hace PrestarLibro.
