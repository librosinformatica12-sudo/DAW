Kit de examen - Cliente + Servidor

Esta página es la versión fácil de leer de los archivos .md. Si abres un .md con Notepad verás símbolos raros (#, **, tablas con |); no es que esté mal, es que Notepad no interpreta Markdown. Usa mejor esta página.

Importante: las soluciones están dentro de cada ejercicio en la carpeta solucion/. No las abras hasta haber intentado rellenar los huecos. En las páginas de ejercicios, la solución está escondida dentro de un desplegable que pone "Ver solución".

1. Chuletas: empieza por aquí

Chuleta de cliente HTML + CSS + JS: seleccionar, eventos, DOM, arrays, random y los huecos típicos. Chuleta de servidor PHP + MySQL: formularios, $_POST, mysqli, procedimientos y códigos de error. Guía del kit Qué hay, cómo estudiar y cómo probar los ejemplos.

2. Ejercicios de cliente

01 - Tragamonedas Como tu TragaPerras: botones, random, créditos y premios. 02 - Lista de tareas Añadir, borrar y completar tareas usando el DOM. 03 - Adivina el número Número aleatorio, intentos, validación y mensajes. 04 - Carrito Array de objetos, cantidades, totales y tabla. 05 - Slider y botones Input range, variables, funciones, botones bonitos y animaciones CSS. 06 - Espaciado de letras Slider para controlar el espacio entre letras y animación de latido. 07 - Espaciado flexible Slider para separar tarjetas y animación de balanceo en cadena.

3. Ejercicios de servidor

01 - Clínica / Citas Formulario, sesión, altas, modificar, borrar y JOIN con doctores. 02 - Conciertos Tu proyecto completo: conciertos, entradas y compra. 03 - Biblioteca Libros, socios, préstamos, stock y devoluciones.

4. Cómo practicar (sin agobiarte)

  1. Lee la chuleta del lado que vayas a practicar: cliente o servidor.
  2. Abre un ejercicio y no mires la solución. Intenta rellenar los huecos en un archivo nuevo.
  3. Si te atascas, abre "Ver solución" y compara solo ese hueco.
  4. Repite el ejercicio al día siguiente sin mirar. Eso es lo que se queda.
  5. Para servidor: importa el .sql en phpMyAdmin y abre el portal_*.html del ejercicio.

5. Datos que tienes que recordar

  • Usuario de MySQL de los ejemplos: root. Contraseña: 1234.
  • El ejemplo de conciertos usa la base gestor_conciertos_examen para no borrar tu base real gestor_conciertos.
  • Si tu MySQL usa otra contraseña, cámbiala en el AccesoDatos.php del ejercicio.
  • Flujo del servidor: form - $_POST - validar - bind_param - CALL - @resultado - mensaje - tabla.
  • Flujo del cliente: getElementById - addEventListener - función - textContent / setAttribute.
Si estás en el examen: abre esta página en el navegador y usa Ctrl + F para buscar cosas como getElementById, addEventListener, bind_param, PA_ o @resultado. Es más rápido que buscar en Notepad.
